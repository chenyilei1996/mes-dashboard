1打开与登录

浏览器地址栏访问看板网址，用 OA 账号登录即可，无需单独注册、无需记新密码。

  1. 打开看板地址（信息中心统一发布，收藏夹存一个就行）。
  2. 未登录会自动跳到 OA 登录页：输入 OA 账号密码（或在已登录 OA 的电脑上直接通过）。
  3. 登录后回到看板首页，右上角能看到自己的名字和可看的范围，即成功。
看不到某个厂的数据？ 各事业部的数据分开授权，找本部门主管或信息中心开通即可。

2看哪个厂、哪段时间

页面顶部两行是全局筛选，改完后整页数据跟着变。

  1. 第一行「个护 / 美发器 / 熨烫」标签：切换要看的事业部。
  2. 第二行日期：手选起止日，或点 昨天本月上月近7天 等快捷键，再点 查询。

3六大指标怎么读

每张卡片 = 一个指标，从上到下四行信息：

  1. 右上角标签：绿色「达标」/ 红色「未达标」/ 灰色「暂无数据」——先看颜色就知道好坏。
  2. 大数字：所选时间段的整体水平（按分子分母汇总计算，不是每天简单平均）。
  3. 目标 / 红线：目标线是管理要求，红线是考核底线。
  4. 最新：区间内最后一天的单日值，看趋势用。
六大指标：计划达成率、工单齐套率、首件及时率、巡检执行率、生产直通率、注塑 OEE。

4点卡片看差在哪

点一张指标卡，下方会自动带出对应的「未完成 / 延期明细」，直接定位到具体工单、线体。

  1. 例如点「首件及时率」卡 → 下方列出哪些排产单没做首检、哪些超了 60 分钟。
  2. 明细支持按车间筛选，也可以单独导出。
  3. 点其他卡片，明细跟着切换；再点当前卡片可收起。

5趋势与车间对比

  1. 指标趋势：折线看走势，绿色虚线是目标、红色虚线是红线；下拉可换指标。
  2. 维度分解：横向条形图看各车间（或产线）谁高谁低；「车间 / 产线」下拉可切换层级。

6这个指标怎么算的？点「?」

指标名旁边的小问号，点开是一句话说清取值逻辑；完整算法、口径变更记录在管理后台留档，需要时找信息中心查看。

7导出数据

  1. 导出 Excel（右上角绿色按钮）：把当前厂 + 当前时间段的全部数据导成多工作表文件，含口径说明页，周会直接用。
  2. 导出 CSV：导明细长表，适合自己再做加工。
  3. 每张图表右上角还有单独的「导出」，只导那一张。

8月度填报（业务方最重要的事）

点页头「月度数据填报表单」进入填报页。系统自动带出上月各指标实际值，并只把未达标的指标勾出来要求填写——达标的自动收起不用管。

  1. 核对指标卡上的实际值；与现场不符可点「手动修正」改写（会标注为手动值）。
  2. 每个未达标指标填写「原因分析」（必填）和「整改措施」。
  3. 有证据材料的（整改前后照片、报表截图等）点「上传附件」，单个 ≤30MB。
  4. 点提交。同一月份重复提交会覆盖更新，放心修改。
  5. 填完可点页头「汇总查看」核对本部门整体情况。
什么时候填？ 每月月初填报上月数据，信息中心会在群里提醒；逾期未填的部门会被点名。

9提意见

看板哪里不好用、想看什么新数据，点右下角蓝色按钮直接说，信息中心在后台逐条处理。

  1. 点右下角「提意见」按钮。
  2. 选类型（建议 / 提需求 / 优化 / 缺陷 / 提问），写清楚「哪个页面、什么问题、希望怎样」。
  3. 有截图或表格可点「选择文件」附上（最多 3 个，单个 ≤30MB）。
  4. 可署名也可匿名，提交即达后台。

?常见问题

为什么昨天的数据是空的？
数据每天早上 06:30 同步一次；当月数据要等次月初才完整，月初几天看上月属正常。
我和同事看到的数字不一样？
先看两人选的厂和时间段是否一致；仍不同则是授权范围不同（有人只看得到本车间）。
指标达标了，为什么还要我填报？
填报针对的是「未达标」项；达标项系统自动收起。若首件 / 巡检有未完成单，即使指标达标也会出现在品质专项清单里，需要说明。
数字和 MES 报表对不上？
先点「?」看口径说明；仍对不上就点右下角「提意见」注明单号与两边数字，信息中心逐单核对。
手机上能看吗？
可以，页面自适应手机屏；主要功能（看数、提意见、公告）手机都能操作。
没找到你的问题？补充在这里
写清楚你想问的（比如"为什么齐套率和我在 MES 看到的不一样"），信息中心收到后会解答，并把高频问题补进本页 FAQ。
